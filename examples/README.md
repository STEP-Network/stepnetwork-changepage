# Examples

Where to put the one call in common routers. In every case: after the new view has rendered, never on the first load.

- [nextjs-app-router.jsx](nextjs-app-router.jsx)
- [nextjs-pages-router.js](nextjs-pages-router.js)
- [nuxt-plugin.js](nuxt-plugin.js)

- [sveltekit.js](sveltekit.js)
- [hash-router.js](hash-router.js)

`getPageData()` in each example stands for however the publisher already exposes page metadata.
